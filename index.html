Créer l'espace de mon foyer

Environ 10 minutes · n'importe quelle adresse e‑mail

Comment ça marche

  1. Indiquez votre adresse e-mail : vous recevez un code à 6 chiffres.
  2. Créez votre espace avec le code d'invitation reçu dans le message.
  3. Répondez à quelques questions sur votre foyer : vos rappels se mettent en place.
